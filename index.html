Keamanan API Key
API Key dikirim ke backend melalui HTTPS dan disimpan dalam bentuk terenkripsi di database. API Key tidak akan ditampilkan kembali setelah penyimpanan. Jangan bagikan API Key kepada orang lain.

Status tersimpan hanya memastikan bahwa kredensial tersedia di database. Status ini belum membuktikan bahwa API Key valid atau bahwa unggah audio ke Roblox sudah berfungsi.

🎵 Pilih Audio

Pilih audio yang kamu miliki atau yang penggunaannya sudah mendapat izin. File lebih dari 5 MB akan ditolak.
Fitur tautan YouTube belum aktif. Gunakan file audio yang kamu miliki atau yang diizinkan untuk digunakan.
Fitur tautan SoundCloud belum aktif. Gunakan file audio yang kamu miliki atau yang diizinkan untuk digunakan.
